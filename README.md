# CyberDefenders Labs

Interactive and practical blue team labs and digital forensic investigations using CyberDefenders.

## Summary

This repository contains practical cybersecurity lab reports focusing on defensive security, threat hunting, digital forensics, and incident response.


## Skills Developed

- Digital forensics and incident response
- Network and PCAP analysis
- Threat hunting and detection
- Malware analysis
- Log analysis
- Identifying indicators of compromise

Repository Structure

Each folder contains an individual lab including relevant investigation, findings, screenshots and reports where applicable.

```text
CyberDefenders-SOC-Labs/
├── README.md
├── CyberLabs SOC-L1-PsExec-Hunt/
│   ├── README.md
│   └── screenshots/
└── CyberLabs-SOC-L1-RetailBreach/
    ├── README.md
    └── screenshots/
 
```

*The folder titles indicated above serve as illustrations; the actual folders contain the laboratories described in this repository.*
